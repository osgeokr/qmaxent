# ⑤ 조사지점 선정

다섯 번째 탭 **⑤ 조사지점 선정** (Survey Site Selection, v0.1.x의 Priority Sites
for Survey)은 서식적합도 래스터를 **현장 조사지점 목록** 으로 변환합니다.
새 개체군 발견과 모델 검증이라는 두 가지 다른 목적이 있고, QMaxent는 목적마다
다른 표집 전략을 제공합니다.

## 단계별 따라하기

### 1단계. 목적과 조건 정하기

![고적합도 탐색 모드의 조사지점 선정 탭](images/steps/ko/s01_survey_discovery_settings.png){ .qm-shot width="680" }

1. **조사 목적**: **고적합도 탐색**은 적합하지만 조사하지 않은 곳에서 새 개체군을 찾습니다.
   **적합도 구간별 층화 표집**은 예측 적합도 구간 전반에서 모델을 확인합니다(2단계).
2. **고적합도 탐색 설정**: **최소 적합도**와 **샘플링 순서**(**무작위** 또는
   **Top-N (적합도 높은 순)**)입니다.
3. **샘플링 전략**: 조사지점 수, 기존 출현지와 지점 사이의 최소 거리(미터)입니다.
4. **▶ 조사지점 선정**을 누르면 선정이 시작됩니다.

### 2단계. (검증 조사) 적합도 구간별 층화 표집

![적합도 구간별 층화 표집을 고른 화면](images/steps/ko/s02_survey_validation_settings.png){ .qm-shot width="680" }

1. **적합도 구간별 층화 표집**을 고릅니다.
2. **구간별 층화 표집 설정**: **임계값 방법**이 포함할 가장 낮은 적합도를 정합니다.
   그 위의 셀을 적합도 구간 네 개로 나누고 구간마다 지점을 고르게 배치합니다.

### 3단계. 주소와 출력 파일

![역지오코딩과 출력 영역](images/steps/ko/s03_survey_geocode_output.png){ .qm-shot width="680" }

1. **역지오코딩**: **행정구역 주소 자동 추가 (OpenStreetMap)**를 켜면 지점마다 주소를
   기록합니다. **주소 언어**로 현지어나 다른 언어를 고릅니다. 인터넷 연결이 필요합니다.
2. **출력**: GeoPackage 경로와 **QGIS 프로젝트에 자동 추가**입니다.

### 4단계. 실행하고 결과 확인

![진행 막대와 상태 줄이 표시된 선정 진행 화면](images/steps/ko/s04_survey_running.png){ .qm-shot width="680" }

1. 진행 막대입니다.
2. 상태 줄입니다. 예: 역지오코딩 진행 수.

![선정이 끝난 화면](images/steps/ko/s05_survey_done.png){ .qm-shot width="680" }

1. 선정된 지점 수와 파일 저장 위치가 표시됩니다.

![조사지점이 지도에 표시된 QGIS 주 화면](images/steps/ko/s06_main_survey_map.png){ .qm-shot width="1440" }

1. 조사지점 레이어가 **레이어** 패널에 추가됩니다.

## 조사 목적

하나 선택:

| 모드 | 목표 | 참고문헌 |
|---|---|---|
| **고적합도 탐색** | 미조사 지역에서 새 개체군 찾기 | Williams et al. 2009 |
| **적합도 구간별 층화 표집** | 예측 적합도 구간 전반에서 모델 확인 | Rhoden, Peterman & Taylor 2017 |

v0.1.x의 Discovery 모드가 고적합도 탐색, Validation 모드가 적합도 구간별 층화
표집입니다. 두 모드는 모델에 매우 다른 질문을 던지므로, 패널 나머지가 선택된
목적에 따라 두 가지 다른 구성으로 전환됩니다.

## 고적합도 탐색 모드

![고적합도 탐색 모드의 조사지점 선정 탭](images/steps/ko/s01_survey_discovery_settings.png){ .qm-shot width="680" }

학습된 모델이 **높은 적합도** 를 예측한 위치에서 조사지점을 뽑아, 현장 팀이
가장 유력한 서식지에 조사 노력을 집중하도록 안내합니다.

### 고적합도 탐색 설정

- **최소 적합도**: 적합도가 이 값 이상인 셀이 후보 풀이 됩니다. 예측 래스터가
    선택되면 *래스터 최댓값 × 0.9* 로 자동 채워져 가장 유망한 영역만 포착합니다.
    더 넓은 후보 풀을 원하면 0.7 등으로 낮추세요.
- **샘플링 순서**:
    - **무작위**: 고적합도 영역 안에서 균일 무작위 표본. 후보 풀의 공간 커버리지를
        원할 때.
    - **Top-N (적합도 높은 순)**: 가장 적합도 높은 *N*개 셀 선택. 정말 최고 지점만
        방문해야 할 때.

### 샘플링 전략

목적과 무관하게 조사지점 집합을 형성하는 세 개의 수치 컨트롤:

- **조사지점 수**: 선정할 지점 수(기본 20).
- **기존 출현지로부터 최소 거리 (m)**: 어떤 출현 지점으로부터의 이 반경
    이내 표본을 금지. 기본 1,000 m. 출현 지점이 GPS 부정확하거나 알려진 곳에서
    멀리 떨어진 진정한 새 개체군을 찾고 싶으면 증가.
- **지점 간 최소 거리 (m)**: 이미 선택된 지점으로부터의 이 반경 이내 표본을
    금지. 기본 500 m. 조사지점을 고적합도 영역에 분산.

### 역지오코딩

**행정구역 주소 자동 추가 (OpenStreetMap)** 를 체크하면 QMaxent가
[OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/) 에 질의해 각
조사지점에 사람이 읽을 수 있는 주소를 추가합니다. API 키가 필요 없고, Nominatim
[사용 정책](https://operations.osmfoundation.org/policies/nominatim/)에 따라 초당
1건으로 요청합니다. 20개 지점이면 약 20초가 걸립니다.

역지오코딩은 전 세계 어디서나 동작합니다. **주소 언어** 로 행정구역 이름의
언어를 고릅니다:

| 옵션 | 결과 |
|---|---|
| **현지 이름** *(기본)* | 각 나라의 언어 (예: 도미니카공화국은 스페인어, 한국은 한국어) |
| **QGIS 화면 언어** | QGIS에 설정된 화면 언어 |
| **영어** | 영어 이름 (OpenStreetMap에 있을 때) |

주소는 다음 필드에 들어갑니다. 모두 OpenStreetMap의 일반 행정 단위이며 특정 나라
전용이 아닙니다:

| 필드 | 수준 | 예 |
|---|---|---|
| `country` | 국가 | 대한민국, República Dominicana |
| `province` | 광역 행정구역 | 한국의 도, 도미니카공화국의 provincia, 미국의 state |
| `city_county` | 시군구 수준 | 한국의 시/군/구, 도미니카공화국의 municipio |
| `district` | 읍면동, 리 수준 | 한국의 읍/면/동, 도미니카공화국의 distrito municipal, sección |
| `display_name` | 전체 주소 문자열 | |

하위 단위일수록 OpenStreetMap의 자료 상태에 따라 빈 값이 나올 수 있습니다.

## 적합도 구간별 층화 표집 모드

이 모드는 새 현장 조사로 예측 적합도 구간을 확인하거나 반증하기 위한 것입니다.
Rhoden, Peterman & Taylor (2017)에 따라 임계값 이상인 셀을 **적합도 4분위로
나누고 각 구간에서 같은 수의 지점을 뽑습니다**. 낮은 적합도 지점도 일부러
포함하므로, 현장 조사 결과로 실제 출현이 예측 적합도 구간을 따르는지 확인할 수
있습니다.

### 구간별 층화 표집 설정: 임계값 방법

임계값은 **표집 범위만 정합니다**. 임계값 이상인 셀이 표집 대상이 되고, 이
셀들을 4분위로 나눕니다. 이진(적합/부적합) 지도는 만들지 않습니다.

| 방법 | 정의 | 참고문헌 |
|---|---|---|
| **MTP** | *Minimum Training Presence*: 어떤 출현 지점에서의 최저 적합도 | Pearson et al. 2007 |
| **T10** | *10% Training Presence*: 일부 이상치 출현에 강건 | Pearson et al. 2007 |
| **MaxSSS** | *Maximum Sum of Sensitivity and Specificity*: 학습 자료 ROC에서 민감도와 특이도의 합이 최대인 값 | Liu, White & Newell 2013 |
| **사용자 지정** | 사용자가 직접 값 선택 | — |

MTP를 고르면 가장 넓은 범위에서 표집하고, MaxSSS나 T10을 고르면 범위가 좁아져
비교적 적합도가 높은 셀 안에서 구간을 나눕니다. 선택한 방법으로 계산한 값은
**계산된 임계값** 칸에 표시됩니다.

## 출력

- **출력 벡터 layer**: 기본 경로는 출력 폴더의 `survey_sites.gpkg` 입니다.
    각 조사지점이 점이며 속성 `id`, `lat`, `lon`, `suitability`, `quartile`
    (적합도 구간별 층화 표집에서는 1~4, 고적합도 탐색에서는 0), 그리고
    역지오코딩이 켜진 경우 위의 주소 필드를 가집니다.
    같은 이름의 GeoPackage가 이미 있으면 새 결과로 교체합니다. 다른 프로그램이
    그 파일을 열고 있어 지울 수 없으면 `survey_sites_1.gpkg` 처럼 다음 빈 이름으로
    저장합니다.
- **QGIS 프로젝트에 자동 추가** *(기본 켜짐)*: `Survey sites` 레이어가 기본 빨간 점
    심볼과 함께 로드되어 적합도 지도 위에 조사지점을 즉시 볼 수 있습니다.

Bradypus 모델에 고적합도 탐색을 실행한 후 (**▶  조사지점 선정** 클릭):

![선정이 끝난 조사지점 선정 탭](images/steps/ko/s05_survey_done.png){ .qm-shot width="680" }

상태 줄은 "✓ 조사지점 20개 선정 완료 (MinSuit = 0.9000); 19/20 지오코딩 완료" 처럼
보고합니다. 한 지점은 외해 위에 떨어져 지오코딩에 실패했는데, Nominatim에 그곳의
주소 기록이 없기 때문입니다.

조사지점이 적합도 지도 위에 표시됩니다:

![Bradypus 적합도 지도 위에 빨간 점으로 표시된 조사지점](images/maps/priority-sites-on-canvas.png)

## 조사 설계 팁

- **두 모드를 함께 실행**: 현장 예산이 있다면 둘 다 실행하세요. 고적합도 탐색은
    확인할 새 개체군 후보를 주고, 적합도 구간별 층화 표집은 모델 정확도 추정을
    줍니다.
- **자동 설정된 최소 적합도를 재정의**: 연구 시스템의 "높음"이 모델과
    생물학적으로 다를 때. Bradypus의 cloglog 0.9는 우림 핵심을 포착하고, 고산종은
    더 낮게 조정합니다.
- **간격 제약을 활용**: 조사 일정 안에 실제로 지점에 도달할 수 있도록. 지점 간
    기본 500 m는 도로로 접근하는 조사에 적당하고, 지점마다 여러 날 이동이 필요한
    서식지라면 늘리세요.
